TRADING WITH NIPUL GALAPPATHTHI — STUDENT RESOURCE HUB
======================================================

Included:
- index.html: responsive website
- settings.js: update timetable links, student group link, and feedback photo list
- assets/feedbacks/: place student feedback images here

IMPORTANT
This is a ready-to-publish website starter, not yet a live/published website.
I cannot publish it into your Google account directly.

QUICK PREVIEW
Open index.html in a browser. Some browsers may restrict local files; publishing it is the best test.

TO UPDATE MONTHLY TIMETABLES
1. Upload the new timetable PDF/image to Google Drive.
2. Set the file sharing to "Anyone with the link" if it is okay for the timetable to be public.
3. Copy the share link.
4. Open settings.js and replace ADD_LINK_HERE for onlineTimetable and/or physicalTimetable.
5. Publish the updated files.

TO ADD STUDENT FEEDBACK PHOTOS
1. Put the photos in assets/feedbacks/.
2. Open settings.js.
3. Add each photo path to feedbackPhotos, e.g.
   "assets/feedbacks/student-feedback-01.jpg",
4. Publish the updated files.
Only post student photos/results with their permission, and avoid exposing private information.

TO ADD THE STUDENT GROUP LINK
Replace ADD_LINK_HERE for studentGroupLink in settings.js with the invite link.

FREE HOSTING
This static site can be hosted on a free static hosting service such as GitHub Pages.
To use GitHub Pages, create a repository, upload index.html, settings.js, and assets, then enable Pages in the repository settings.
Updating from a phone is possible through GitHub's web interface, but editing files and uploading photos may take a few steps.
